# Frontend Phase 4 sonuç raporu

23 Ekim 2026. Yalnızca onaylanan Phase 4 uygulandı. Önceki Phase 3 çalışmaları ve kullanıcıya ait değişiklikler korundu.

1. **Değişen dosyalar:** mobilde CalendarScreen, AuthScreen, HomeScreen, PasswordResetScreen; yeni occurrences/{shared,MonthNavigation,HistoryScreen,OccurrenceScreen} ve analytics/{Charts,AnalyticsScreen}; finance contracts/api/queries/money/components/PaymentFormScreen; DateField, PreviewBanner; root layout ve analytics/occurrence/payment-history/forgot-password/reset-password route'ları; password-reset service; package/lock/app.json, Jest setup ve ilgili testler. Backend'de AuthController, AnalyticsController, PayAheadApi/SharedRateLimitMiddleware/DI; Application PasswordReset/Analytics/OverviewService; Domain PasswordResetToken; Infrastructure PasswordResetStore/SmtpPasswordResetEmail/PasswordResetEmailWorker, AuthStore/AccountStore/DI, migration/designer/snapshot; Foundation/Overview/FrontendPhase4 testleri. `.env.example`, Docker email compose, README ve docs güncellendi. Önceden değiştirilmiş API csproj/appsettings.Development ve production-operations-review.sql bu fazda değiştirilmedi.
2. **Takvim/geçmiş:** gerçek aylık calendar, server Today, ileri/geri ve bugün, gün seçimi/durum noktaları; geçmiş ay/durum ve 20 satır pagination. Gelecek DueDate geçmiş gibi sunulmaz. Empty/loading/error/retry/pull-refresh vardır. Plan ve occurrence ayrı ekranlardır.
3. **Durumlar:** Paid/Skipped/Pending mevcut API üzerinden; exact actualAmount ve rowVersion. PaidAtUtc sunucuda atanır. Aktif olmayan geçmiş salt okunur. Çift gönderim kilidi, 409 ve sonucu belirsiz ağ hatasında açık reload, kullanıcı/epoch cache invalidation vardır. Bankadan tahsilat yapılmaz.
4. **Tarih seçici:** Expo Go SDK57 datetimepicker9.1.0; başlangıç/bitiş, mevcut tarih, end-date alt sınırı, isteğe bağlı temizleme. UTC string dönüşümü kullanılmaz; yerel yıl/ay/gün parçaları korunur. Ay sonu/artık yıl ve iptal testleri geçti; native dokunmatik/geri tuşu bekler.
5. **Şifre sıfırlama:** anonymous forgot/reset formları; generic202, kısa expiry, hash-only SQL, tek kullanım, yeni parola validation, refresh-family revoke ve yerel session/cache temizliği. Güvenli kod/bağlantı fallback; kalıcı token deposu eklenmedi.
6. **E-posta:** Türkçe markalı HTML, SMTP abstraction, TLS production kontrolü, bounded memory queue ve güvenli failure logları. Gerçek TCP SMTP MIME yakalama testi geçti. API e-posta servis testleri kontrollü delivery double kullanır. Mailpit Compose hazır; dış posta kutusuna teslim/gerçek provider/telefondan e-posta kabulü yapılmadı. [Kurulum](../../docs/PASSWORD_RESET.md).

8. **Endpoint'ler:** mevcut `GET /api/calendar`, `/api/payments/upcoming`, `/api/payments/{id}` ve `/api/payments/{id}/occurrences/{date}`; `PUT .../{date}/status`. Yeni `POST /api/auth/forgot-password`, `POST /api/auth/reset-password`, `GET /api/analytics`. [Semantik ve response alanları](../../docs/ANALYTICS.md).
